# ADR-0001：采用本地优先的浏览器工作台架构

状态：接受  
日期：2026-09-10

## 背景

用户需要处理最高 1 GB 的表格数据，并要求数据不上传外部服务、浏览器关闭后长任务继续执行、任务可恢复，同时希望使用熟悉的网页交互方式。

## 决策

采用 Windows 桌面启动器、本地 FastAPI 服务、React 浏览器前端和独立 Python 工作进程。项目数据保存在用户选择的本地项目库，元数据使用 SQLite，内部工作数据使用 Parquet。

## 影响

- 获得浏览器交互体验，同时保留 Python 数据生态和本地文件性能。
- 前后端需要版本协议及统一打包，安装包体积会高于纯网页应用。
- 不能依赖云端任务队列、云存储或在线模型服务。
- 本地端口、令牌、路径校验、日志脱敏和更新机制成为必须测试的安全边界。
