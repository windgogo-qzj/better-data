# Better Data v0.1.1

`v0.1.1` 是首个 MVP 可用性修订版本，重点完善首页叙事、统一项目流程、项目回收站、CSV 导入兼容和 Windows 删除可靠性。

## 主要变化

- 首页改为两个完整视口：产品介绍与五阶段交互流程。
- 流程操作台与页面滚动相互隔离，五个阶段使用不同视觉表达且不遮挡内容。
- 创建到导出统一为七阶段导航，每个业务阶段都有稳定 URL。
- 工作台修复侧栏遮挡，项目库、搜索、回收站和设置的展示关系更清晰。
- 项目支持移入回收站、撤销、恢复和永久删除。
- CSV 增加 GB18030 与 Windows-1252 编码回退，失败导入不再遗留半成品项目。
- README 增加同一脱敏数据集的首页、创建、诊断和最终结果截图，以及完整使用说明。

## 修复重点

- 删除对话框不再显示 `undefined`。
- Windows 目录短暂占用时使用安全移动回退。
- 回收与恢复后列表以服务端真实状态为准。
- 第二次导入不同编码 CSV 时不再产生无法继续的失败项目。
- 首页完整切屏不再残留上一屏内容。
- 产品流程右侧视觉不再被结果浮层覆盖。
