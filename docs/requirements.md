# Better Data v1.0 产品需求规格

状态：已冻结  
目标平台：Windows 10/11 64 位  
交付形态：桌面启动器、本地后端、浏览器工作台

## 1. 用户与目标

目标用户具备基础数据分析能力，但不希望手写完整的数据预处理和特征工程流程。产品需要把繁琐步骤组织为可解释、可调整、可恢复、可复现的本地流水线。

核心流程为：上传数据、配置任务、确认字段、分析质量、审阅建议、预览影响、执行流水线、对比与导出。

## 2. 输入与任务

- CSV 文件最高 1 GB；保证导入、扫描、抽样分析及流式兼容步骤的执行。
- XLSX 文件最高 200 MB；一次处理一个工作表，读取公式缓存值，不执行公式，不支持密码文件。
- 分类和回归必须指定目标列，默认按 80%/20% 划分训练集与测试集。
- 分类支持分层划分；同时支持随机、时间和分组划分。
- 聚类模式只完成预处理与诊断性评估，不输出最终聚类标签。
- 纯清洗和聚类模式默认处理完整数据，不强制划分训练集与测试集。

## 3. 字段角色

系统推断并允许用户修正：连续数值、离散数值、名义类别、有序类别、布尔、日期时间、ID、文本、目标、分组、敏感和忽略字段。文本字段在第一版保留但默认不参与特征处理。

## 4. 数据质量与推荐

质量评分由完整性、有效性、一致性、唯一性、结构可用性和任务就绪度组成。总分仅用于启发式对比，必须同时展示分项分数和扣分原因。

每条建议必须包含问题证据、严重程度、置信度、推荐操作、参数、预计影响、潜在副作用、替代方案和稳定的规则编号。

默认阈值：

- 高缺失列：缺失率不低于 50%。
- 近常量：单一值占比不低于 99%。
- ID 候选：唯一率不低于 98%，并结合字段名、格式和单调性判断。
- 高基数类别：类别数超过 50 或预计编码维度过大。
- 稀有类别：占比低于 1% 或数量低于 20。
- 高相关：相关系数绝对值不低于 0.95。
- 潜在和极端异常：分别超过 1.5 和 3 倍 IQR。
- 类别不平衡和严重不平衡：最小类别占比分别低于 20% 和 10%。

阈值可按项目调整并保存为全局默认值。低风险操作默认选中；中风险推荐可预选但执行前统一确认；高风险及低置信度建议默认关闭。推荐冲突时暂停并交由用户决定。

## 5. 处理能力

- 缺失值：均值、中位数、众数、缺失类别、缺失指示、KNN 和迭代式填充。
- 重复值：完全重复、关键字段重复和目标冲突。
- 类型解析：数字、百分比、货币、科学计数法、日期和 Excel 日期序列。
- 类别处理：空白规范化、大小写建议、相似拼写候选、稀有类别合并和未知类别。
- 异常处理：保留、标记、截断、置空或删除；默认不直接删除。
- 数值处理：标准化、Min-Max、稳健缩放、对数、Yeo-Johnson 和分箱。
- 类别编码：二值、One-Hot、Ordinal、频率及高级目标编码。
- 特征工程：日期衍生、缺失指示、用户指定的比率、差值、和、乘积及少量交互候选。
- 特征选择：常量、重复、高缺失、高相关、单变量统计和互信息。
- 不平衡处理：类别权重、过采样、欠采样和 SMOTE，仅作用于训练集。
- 可选 PCA 或适合稀疏数据的降维方法。
- 用户可设置非空、范围、唯一性、类别集合、格式和日期范围等业务校验规则。

## 6. 泄漏保护

除不依赖统计学习的结构清理外，所有填充、编码、缩放、特征选择和降维参数只允许在训练集拟合，再应用于测试集。测试集新类别映射为未知类别；目标编码需要在训练集内部安全拟合；采样不得改变测试集分布。缺失目标记录单独导出，目标列默认不得填充、截断或参与普通特征生成。

## 7. 评估

评估只设关闭和快速两档。分类使用逻辑回归，回归使用 Ridge 回归。比较对象为最低限度兼容方案和用户确认的完整方案，两者必须使用相同划分、样本、随机种子及指标。

聚类预处理在相同样本上搜索 K=2～10，以临时 K-Means 或 MiniBatch K-Means比较处理前后轮廓系数、Calinski-Harabasz、Davies-Bouldin 和稳定性。结果只表示基线变化，不代表最终模型结论。

## 8. 大数据与资源保护

每个处理组件必须声明是否需要拟合、是否支持分块、是否改变行列数、是否依赖目标、是否支持稀疏数据、资源估计、任务适用性和泄漏风险。系统据此选择全量、抽样、降级或禁用。

执行前需要估计内存、磁盘和输出特征数。One-Hot、分箱和交互特征必须设置可调整的维度上限。基础磁盘预检不少于 5 GB 或原始文件大小四倍，并结合预计输出继续上调。

## 9. 项目与任务

- 首次运行由用户选择项目库，每个项目复制一份原始文件并生成内部 Parquet 工作副本。
- 后台大型任务默认串行，轻型分析可以并行。
- 关闭浏览器不终止任务；系统托盘负责重新打开、停止和通知。
- 恢复粒度为最近已完成的流水线步骤，不承诺算法内部断点续算。
- 修改上游步骤后必须使受影响的下游缓存失效。
- 展示项目磁盘占用，支持缓存清理、保留期限、回收站删除和二次确认的永久删除。

## 10. 页面

项目首页、上传数据、任务配置、字段确认、数据质量报告、处理方案、执行中心和结果中心共八个主要页面。

## 11. 导出

默认导出 UTF-8 BOM CSV；满足 Excel 限制时可导出 XLSX；完整结果导出为 ZIP。ZIP 包含数据、单文件离线 HTML 报告、配置、结构定义、已学习参数、Python 脚本、依赖说明、日志及文件哈希。

Python 脚本区分复现模式和新数据转换模式，并提供严格和兼容两种结构校验。KNN 状态可能包含训练参考数据，导出时必须提示体积和隐私风险，并允许改用简单填充。

## 12. 非功能要求

- 数据和报告不上传外部服务；更新检查可选且默认关闭。
- 服务只监听本机地址并使用随机访问令牌。
- 报告内容必须转义，敏感字段不得进入普通日志。
- 原始文件永不被原地修改。
- 可复现性以锁定依赖版本、输入哈希、配置版本、随机种子及明确数值误差为准，不承诺跨任意环境逐字节一致。
- 第一版仅提供中文界面，不涉及账号、登录和多用户协作。

## 13. 明确不包含

文本 NLP、图片音频、时间序列专用建模、最终模型训练调参部署、最终聚类标签、数据库和云盘输入、多文件关联、多工作表联合分析、PDF 报告、在线协作以及界面内任意 Python 代码执行。
